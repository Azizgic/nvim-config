# Neovim Configuration

## Installation

1. Backup your current Neovim config (optional):

```bash
mv ~/.config/nvim ~/.config/nvim.backup
```

2. Clone this repository:

```bash
git clone https://github.com/Azizgic/nvim-config.git ~/.config/nvim
```

3. Open Neovim and install plugins with lazy.nvim:

```vim
:Lazy sync
```

4. Done! Your configuration should now be loaded.
